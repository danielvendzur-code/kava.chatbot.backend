# Vizuálny profil vône — požadovaná úprava 15 ukážok

Majiteľ žiada odstrániť „Najviac 2 kroky podľa ďalších odpovedí“ a pomocné „Vyberte podľa uvedených tónov“, doplniť zaujímavejší výsledok. UI opt-in sa týka existujúcich 15 neposlaných parfumových ukážok, nevznikajú nové firmy. Pôvodných 17 registrácií sa nemení.

Výsledok má otvorený farebný profil: Hlava / Srdce / Základ len pri doslovne uvedenej pyramíde. Inak zobrazuje vybrané existujúce, zdrojovo overené tóny z už používaného profilu. Oficiálne vonné rodiny sa zobrazujú iba pri existujúcom explicitnom zdrojovom poli. Rovnaké riadky a farebné značky nepredstavujú percentá ani intenzitu. Zoznam tónov neuvádza pomery či skóre 1–10, preto sa tieto čísla nevymýšľajú.

Jadro c9, katalógy, ceny, balenia, sklad, identita výrobkov, doplnky aj odpovede backendu zostávajú nezmenené. Nové sú iba prezentačný config a CSS, opt-in podmienka pre poznámku priebehu a profilový renderer. Žiadna produkcia/DNS/pošta/platené volania. Pôvodné dôkazy zachované; nová lokálna a živá kontrola vzhľadu prebieha pred finálnym odovzdaním novej verzie.
